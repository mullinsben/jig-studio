How it works

  1. On any page, click the bookmark. The jig loads from this site and turns on; nothing is written to the page you're on.
  2. Everything it can find becomes adjustable: cover-cropped images, text, buttons, sections, text overlays. The grid, device frames, and protection scan work as usual.
  3. No foundation file on a foreign site, so the jig reads the page's CSS variables or infers scales from the rendered page; advanced → foundation shows what it decided and lets you correct it.
  4. Copy patch. The patch names the page URL, so the person (or AI) applying it knows where it goes, and it carries the proposed tokens.
Some sites ship a strict Content-Security-Policy that blocks injected scripts (most large apps, banks, GitHub). The bookmarklet can't get past that; nothing will happen and the console will say why. A browser extension can, and is on the list.
